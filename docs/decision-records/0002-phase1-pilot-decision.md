# Phase 1 pilot decision record

The first pilot is the authorized deterministic synthetic workflow specified in
`docs/pilots/phase1-synthetic-protocol.md`. Its reproducible command and
configuration are bundled under `examples/phase1_calibrated`.

Before a release decision, run the documented command in a clean environment
and archive its complete evidence bundle. Record certificate, candidate,
unresolved, abstention, and `full_worse_than_reduced` counts here. Proceed only
if the bundle is reproducible and the diagnostic pattern is operationally
useful; otherwise extend calibration or redesign as specified in the Phase-1
hand-off.
